# Agent Guidelines

## Interaction Rules
- **Short, simple, direct**: Give concise, straight-to-the-point answers.
- **No fluff**: Avoid conversational filler, preamble, and over-explaining.
- **Exact scope**: Do only what is asked without over-engineering.

## Code Guidelines
- **Simple & declarative**: Write clear, declarative code.
- **Names over comments**: Favor expressive, self-explanatory names over comments.
- **Decompose**: Split large functions and files into smaller, focused pieces.
- **Separate contexts**: Group related logic into distinct files and directories.
- **No magic**: Avoid magic numbers, strings, and hardcoded values.
- **Const correctness**: Use `const` and `constexpr` whenever possible.
- **Avoid logic duplication**: If logic is duplicated, refactor it into a separate function.
